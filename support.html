Help with connecting, sending and importing

SMBDrop sends photos, videos and files from your iPhone straight to your own SMB network shares — a NAS, a Windows or macOS shared folder, or a Samba server — and imports files back. No account, no cloud, no subscription.

Requirements

  • iOS 17 or later.
  • An SMB server you can reach from your network: most NAS devices (Synology, QNAP, TrueNAS, UGREEN…), Windows file sharing, macOS file sharing with SMB enabled, or Samba on Linux.
  • The server's host name or IP address, share name, and a username and password.

Getting connected

  1. Open Settings in SMBDrop and add a share.
  2. Enter the server's host name or IP address. The port is 445 unless your server uses a custom one.
  3. Sign in with the server username and password, then use Find Shares to pick the share instead of typing it.
  4. Optionally browse to a subfolder, then run Test Connection and save.

Common issues

  • Connection times out — check the iPhone is on the same network as the server and that iOS Settings → SMBDrop has Local Network enabled.
  • Sign-in fails — re-enter the username and password; some servers need the plain username without a domain prefix.
  • Share not found — use Find Shares to list the names the server actually exports; hidden ($) shares are not shown.
  • Imports are saved on the iPhone under Files → On My iPhone → SMBDrop → SMBDrop Imports, and appear in SMBDrop's Files tab where you can preview, share, save media to Photos, or delete them.
